## 历史脚本不是跨机器的一键构建

`大肥鱼第二版/装配/` 下的 Python 脚本是制作记录，包含原机器绝对路径和固定输出文件名。原样运行可能失败，或覆盖原机器工程。请先在隔离副本中将输入/输出路径改为自己的路径，再审阅具体逻辑。

| 脚本 | 额外限制 |
|---|---|
| `fix_assembly_f001.py` | 读取原工作区临时目录 `v2fit/fit.json`；该文件不在本次用户指定的源目录中，未补造。 |
| `toon_apply.py` | 从 `外部参考/OC第五版/OC5_anime_toon_v018.blend` 提取特定材质、灯光与世界；该文件现已纳入仓库，但可能仍有外链依赖。直接查看已保存的 t002 与重新执行此脚本是两回事。 |
| `fix_body_f001.py` | 渲染输出指向原工作区临时目录 `v2fix/`，必须先改路径。 |
| 其他装配脚本 | 含原工作区绝对路径；依赖指定版本工程、对象名、报告与数据层。 |

缺少上述早期依赖不等于可以直接重新生成完整流水线。本仓库的主要交付是检查点工程与经验资料。
