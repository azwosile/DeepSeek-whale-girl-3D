# 07 验收矩阵与证据

## 7.1 完整验收矩阵（来自通用手册 §22，按本次经验补充）
| 类别 | 最低检查 | 合格证据 | 常见的假通过 |
|---|---|---|---|
| 源资产 | 几何、材质、UV、权重、动作清单 | `mesh_audit.py` 哈希与结构报告 | 只说“看起来没变” |
| 对齐 | 四视图地标对参考图 | 叠图 + 地标高度差 | 只看包围盒 |
| 静止状态 | 物体间接触、自交、固定端 | 面级报告 + 多视图 | 只检查代理 |
| 骨架权重 | 未赋权、归一化（仅变形骨）、影响数、极限姿势 | 权重报告 + f20/40/60/80 姿势图 | 自动权重没报错 |
| 发根 / 腰线 | 固定区、过渡区、附着例外 | 区域清单 + 运动测试 | 用高度切线一刀切 |
| 对象间碰撞 | 身体、衣物、头发、裙摆、尾巴的完整关系 | 实际求值网格全段报告（静止 / 均值 / 最大） | 只测几个关键帧 |
| 自碰撞 | 发束、裙褶、指间 | 窄相复核 + 结构分类 | 把静止时已有的全部过滤掉 |
| 骨链质量 | 加速度 p95、HF 能量、反转率、弦长、弯曲 | `motion_metrics.py` 报告 | 只看一张 GIF |
| 时间连续性 | 峰值、分位数、局部曲线 | 全序列指标 | 只看平均值 |
| 亚帧 | 指定亚帧采样或适用的 CCD | 采样范围与失败列表 | 把整数帧结论推广到区间 |
| 缓存 | 映射、坐标、索引、路径、重开 | 独立进程复核 | 写出函数返回成功 |
| 渲染 | 正、背、侧、特写，描边与着色时序 | 实际渲染 + 审阅记录 | 好看的一张图 |
| 导出 | 指定格式、回读、目标环境 | 回读报告 | 扩展名正确 |
| 交付 | 场景、缓存、贴图、说明、限制 | 清单与哈希 | 只交 `.blend`，漏了缓存 |

## 7.2 证据等级
1. 独立进程重开后的数值报告 + 亲眼看过的渲染图（最高）
2. 当前进程内的数值报告
3. 渲染图（只看过关键帧）
4. “脚本运行成功”（不能作为通过的证据）

## 7.3 验收图规范
- 四视图一张图，拼成 4×2 网格，上排修改前、下排修改后，同机位、同帧。
- 特写单独出：脸、手、袖口、尾根、鞋、头饰。
- 动作出帧条（例如第 1、100、186 帧）或三视图跟拍视频（侧、正、背）。
- 交给用户的图都要说明：哪个版本、哪一帧、什么机位、看什么。

## 7.4 常见症状的排查顺序（通用手册 §24 加本次补充）
| 症状 | 先查 | 不要立刻做的事 |
|---|---|---|
| 一启用布料就爆炸 | 初始穿透、固定点、碰撞厚度、尺度 | 盲目加步数 |
| 头发一折一折 | 有没有抗弯；限幅和碰撞是否互相推挤 | 加更多碰撞 |
| 头发、尾巴高频抖动 | 弯曲记忆是否在逐迭代硬改位置；尾巴是否每帧被裙子推 | 时间域后滤波 |
| 发根拉成长条 | 两端自由度、硬切线、接触侧 | 解锁整片头发或改脸 |
| 网格只跟随一部分骨骼 | 非变形组是否参与了归一化 | 加大骨骼缩放 |
| 自动权重大片为 0 | 网格多片区、非流形 | 手刷几千个顶点 |
| 眼睛贴图跑到头发上 | 贴图烘焙串色（Tripo） | 改几何 |
| 渲染出现品红色 | 贴图丢失（多个 EEVEE 进程并行、路径） | 重做材质 |
| 导出贴图全黑 | 有效像素、烘焙通道、目标图像 | 只检查文件是否存在 |
| 回读尺寸巨大 | 单位、轴向、辅助对象、重复变换 | 手动缩放全部骨骼 |
| 断线后不知道是否完成 | 命令状态、报告、文件哈希 | 直接重跑写入脚本 |
