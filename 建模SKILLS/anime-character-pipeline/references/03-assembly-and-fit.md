# 03 装配与贴合（f 系列）

## 3.1 顺序
1. 素体修复（f001 body）：去掉 Tripo 素体自带、会和服装冲突的件（例如自带的鞋片区），修明显的破面；脸不动。
2. 整体相似变换对齐服装：s / t 来自地标拟合（肩、腰、胯、膝），写入 `fit.json`。
3. 服装去实心：Tripo 服装常是“实心壳”，内部有封口面，要找出来删掉或挖空，才能套到身上。
4. 分部件局部贴合：袖子对齐手臂轴、裙腰对齐腰线、领口贴颈。
5. 消穿模：先让**内层**（素体）往里收，再把**外层**（头发）往外推，并沿发束平滑传播。
6. 配件逐件装：鞋 → 头饰 → 发饰 → 尾巴（每件单独报告 scale、偏移、穿模采样）。
7. 四视图、特写和参考叠图验收；用户确认后，才进入绑定。

## 3.2 连通片区是分件的起点，不是终点
- 用 numpy 并查集算片区（`mesh_audit.py` 里有实现），按“大小 + 位置 + 颜色”识别，**不要依赖原始片区编号**（重导入以后编号会变）。
- 常用识别规则（大肥鱼第二版实测）：
  - 皮肤 = 最低点 z 最小的那个片区（z 0.019–1.378）。
  - 脸 + 刘海是一个片区（3182 顶点），后发是另一个大片区（z 0.89–1.646）。
  - 服装：裙子、胸衣、袖泡、袖口、纽扣、肩荷叶边各自成片区。
- 片区边界不等于语义边界：头发和皮肤可能连在一起，这时按颜色或 UV 区域切开。

## 3.3 内外判断：不要信法线，用奇偶规则
- Tripo 网格常有双层壳（脸就是双层），法线方向乱。判断一个点是否在封闭体内部：沿某方向发射线，**统计穿过的面数，奇数为内、偶数为外**。
- BVH `ray_cast` 返回 `(location, normal, index, distance)`；循环发射时，每次从命中点稍微前移再继续。
- 开放表面（裙子、袖子）没有“内部”，只能用“最近外层表面 + 指定方向（例如裙摆水平径向）”判断。

## 3.4 消穿模的手法与上限
- 推出头发：沿射线找 0.2 m 内的服装最外层，目标间隙约 6 mm；腰以下的推出方向**水平化**（沿裙子径向），避免把发梢往上下推；位移沿发束平滑扩散。
- 素体内收：只在被服装盖住的区域做，平滑衰减到露出区域，避免露出区域出现台阶。
- 所有位移都要有上限，并统计“新增进入皮肤内部的顶点数 = 0”。

## 3.5 配件装配要点（大肥鱼第二版 f003 实测）
- **高跟鞋**：脚要摆成高跟足姿（鞋按脚长缩放 0.6466，足跟抬 15.16°，整体抬高 2.6 cm）；删除素体自带的鞋片区；把伸进鞋里的皮肤顶点夹到鞋内（135 个）。整体抬高要传给绑定。
- **头饰**：按头宽缩放（1.12），统计两侧间隙（平均 −6 mm 表示略压进头发，可接受）。
- **蝴蝶结**：贴在头发表面外，记录偏移（侧 44 mm、后 24 mm）。
- **鱼尾**：搜索附着点和俯仰角（−0.018, 0, 1.056；21.9°），以穿模采样最少为目标；再把后发中压到鱼尾里的顶点外推。

## 3.6 修复轮（f004 实测的三类问题和做法）
| 用户意见 | 根因 | 做法 | 结果 |
|---|---|---|---|
| 眼睛旁边的发丝上有眼睛贴图 | Tripo 把眼睛颜色烤到了贴在脸前的发丝上 | 在 UV 空间按重心坐标逐面栅格化，在眼带高度（z 1.392–1.509）范围内，用同一发束的头发颜色重绘这些面 | 882 个顶点、1288 个面、约 41.7 万像素 |
| 袖子太长、手穿过袖口 | 袖子比手臂长 | 袖筒和袖口整体沿手臂轴上移约 9 cm，各级袖口单独缩放（1.0–1.5），袖筒内壁外推 ≤ 2 cm | 手露出，袖口不再穿手 |
| 鱼尾 / 后发穿模 | 后发垂落时盖住鱼尾上段 | 按竖列把后发外推到鱼尾外侧（最大 9.3 cm，684 个顶点），沿发束平滑 | 头发在尾内的顶点从 95 降到 3 |

重绘贴图的三个坑：
1. 脸是双层壳，射线判断要用奇偶规则。
2. 重心坐标外扩太大，会把颜色渗到皮肤上；硬边带会留下一条线，要做羽化。
3. 必须限制 |y| > 0.05（眼睛以下），否则嘴唇也会被涂成头发的蓝色。

## 3.7 头发整理（大肥鱼 v1 实测）
- ✗ 拉普拉斯 / Taubin 平滑加拉向平滑代理：指标变好了，但薄条带被压塌，后发透缝，所以否决。
- ✓ 参考剪影约束：四视图剪影配准到渲染网格，超出剪影（留 1.25 cm 余量）的顶点**只做水平回拉**；发际线 4 环渐变；单顶点位移 ≤ 3 cm；呆毛锁定；最后做 ≤ 1.5 mm 的 Taubin 平滑。结果存成**可逆形态键**（Basis = 原始）。
- 头发下端太卷时，沿发丝方向只压平高频卷曲，保留整体发型（卷曲 RMS 3.11 → 1.94 cm）。

## 3.8 体型修改（腰太粗 / 臀太大）
- 腰收细：峰值放在最细处，向上到胸下、向下到臀上缘平滑过渡为 0；**身体和衣服用完全相同的映射**，相对间距保持不变（大肥鱼 v1：腰宽 17.2 → 15.8 cm，臀宽不变）。
- 改体型以后，裙子布料要在新腰围上重新模拟。

## 3.9 验收图怎么做
- 四视图（正、左、背、右）加斜视，和参考图**同网格叠图**（`overlay_ref_vs_model`）。
- 上半身、手、袖口、尾根、头饰、鞋都要出特写。
- 前后对比统一用同一机位、同一帧；文件名写成「阶段_版本_内容.jpg」。
- 用户说“整体错位”时，先在原图上标注地标，再逐个检查对齐。错误的对齐版本保留并标注“错误版_已作废”。
