# 06 卡通渲染、描边与 Paper朱插件（t 系列）

## 6.1 先锁定风格
同一姿势、同一机位、同一灯光下，出两种方向给用户选：
| 项目 | v017 日番硬阴影 | v018 插画式 Toon（**用户选定**） |
|---|---|---|
| 色阶 | 亮暗两档，硬切换 | 三层色阶，中间保留平台，边界柔化 |
| 暗部 | 冷蓝 | 提亮的浅紫阴影，脸部暖色阴影 |
| 高光 | 无 | 受控的头发高光，轻微冷色轮廓光 |
| 描边 | 细黑边 | 更轻的蓝灰 / 深蓝细边 |

做法：Blender 原生 EEVEE（Shader to RGB + ColorRamp）。**不是**把 Unity 的 lilToon 装进 Blender，也没有安装 Goo Engine 或购买 Komikaze，不要混称。

## 6.2 Toon18 的关键设置（可移植到新角色）
- 以自发光为主、带 3 级 Ramp；冷色阴影 (0.70, 0.72, 0.90)，皮肤阴影 (0.92, 0.81, 0.83)。
- 世界 (0.14, 0.18, 0.24)，强度 0.25；四盏灯 Key / Fill / Rim / Sun。
  - 移植到新角色时，要**按新角色的朝向旋转灯组**。大肥鱼第二版正面 +X，灯组绕 Z 轴旋转 90°，例如 Key (4, −3, 5)。
- 在身体上写两个属性：只用于渲染的脸部区域（脸部单独控制阴影，减少写实阴影碎片）、只用于头发的高光遮罩。
- 移植方式：append 已验收工程（OC5 v018）的材质和灯光，按语义映射到新角色。不改网格。

## 6.3 描边（反转外壳）
- 每个对象加一个 Solidify（法线翻转、仅背面材质），厚度按对象分别设置：身体 0.0024、服装 0.0030、饰品 0.0022。**0.0011–0.0014 太细**，看不出描边。
- Tripo 法线不可靠，描边可能出现破洞或内凹。可以试 Paper朱的“修复描边”思路，或先统一法线方向（法线修复会改变外观，要做前后对比）。
- 描边壳要排除在碰撞统计之外，单独处理。

## 6.4 Paper朱二次元渲染助手（参考渲染插件）
- 仓库：https://github.com/PUBG11S1/paperzhu-anime-helper （作者 Paper朱，V1.0 / V2.0“风格色彩版”ZIP）。
- 功能：一键黑色描边（可调粗细）；可选“修复描边”模式，减少描边壳层干扰；高光皮肤材质（可调混合）；二次元风格化色彩管理（可调对比）；一键二次元辉光（可调阈值，会把合成器设为“总是”）。
- 面板：3D 视图 → N 面板 → Paper二次元渲染助手。官方标注适配 Blender 4.1–5.0。
- **本工作区的实测范围（OC5 v016）**：主机是 Blender 5.2.2；没有全局安装插件，也没有改偏好设置。只审阅并临时调用了 V2 `materials.py` 的描边修复和高光材质辅助函数，渲染成功。界面操作和辉光功能未验证，**不能声称整个插件兼容 5.2**。
- 经验：默认高光在深色制服上会形成明显亮斑，需要降低高光和边缘增亮，并减弱脸部描边。
- 用法建议：作为描边和高光的参考实现与快速试验工具。正式工程仍用可哈希验证的脚本化材质（Toon18），插件生成的节点要保存到独立的渲染分支。

## 6.5 必须验证的
- 风格改动前后跑 `scripts/mesh_audit.py` 并对比：拓扑、UV、坐标哈希必须一致。允许的差异只有新增的 Outline 修改器和描边厚度顶点组。
  - 实测 r002 → t002：只多了 `SOLIDIFY:Outline` 修改器和 1 个顶点组。
- 正面、背面、侧面、脸部特写（例如注视点 (0.1, 0.02, 1.49)、正交 0.2–0.3）、手部、尾部都看过。
- 多帧检查：转头或跑步时，看阴影是否跳带、法线是否闪烁、描边是否变粗。
- 贴图里已经画进的褶皱、高光去不掉：加了 ColorRamp 也还在。要么接受，要么分语义区域单独控制。

## 6.6 渲染工程与交换工程分开
Shader to RGB、反转外壳描边、辉光都只在 Blender EEVEE 内有效。GLB/FBX 用独立的简化 PBR 材质，引擎里要另建 Toon 材质。
