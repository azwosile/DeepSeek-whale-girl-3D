# 02 立绘拆图（GPT Images 2.5）与 Tripo 生成

## 2.1 拆成几张
三张就够，额度优先花在头发和裙子上：
1. **素体（带头发）4 视图**：头发做成大块发束，与后背分开。穿白色基础内衬，相当于素体。
2. **服装 4 视图**：隐形人台（ghost mannequin）。**必须把第 1 张素体图作为参考图一起上传**，这样比例和姿势一致，后面才好贴合。
3. **配件合集 1 张**：头饰、发饰、尾巴、鞋等分开摆放、留大间距，按同一比例。

用户规则：**服装的袖子不要去掉**（Tripo 会处理）；**配件图不裁剪，整张导入**，以节省额度。

## 2.2 模型与画幅
- GPT Images 2.5 选 **Sunburst**（精确档）：最能保持参考特征，多轮“只改一处”的编辑控制更紧。Flare 是快速默认档。
- 4 视图：16:9、4K（3840×2160）、质量 max，四个视图横排（每格约 960×2160）。**不要用 2×2 排列**，人物会小一半。
- 配件：3:2（3840×2560）。

## 2.3 每条提示词都要包含的硬要求
| 要求 | 原因 |
|---|---|
| 正交、无透视；四视图同一比例，头顶、脚底对齐 | Tripo 多视图需要严格对齐 |
| A-pose：手臂下张约 45°，手指微分开；双脚分开约一脚宽 | 腋下、腿间留出空隙，网格不粘连，方便绑定 |
| 平光、无投影、无光泽高光 | 光影不会烤进贴图，后面卡通着色更干净（大肥鱼 v1 的“油亮感”就是贴图里烤了高光） |
| 纯色浅灰背景 #C8C8C8，不用白底 | 白色荷叶边和围裙在白底上会被抠掉 |
| 无文字、标签、边框、地面阴影 | 避免被当成几何体 |
| 闭嘴微笑、中性表情 | 张嘴会被做成几何体；虎牙以后用贴图或形态键加 |
| 第 2 格：她的左侧朝镜头，脸朝画面左；第 4 格：右侧朝镜头，脸朝画面右 | 与 Tripo 的 left/right 对应（用前在 Tripo 界面确认） |

## 2.4 安全审核
skin-tight bodysuit、mannequin、bust、crotch、thigh gap、bare feet 等词组合在一起容易被拦截。
- 改写为“游戏设定图的基础服装：白色长袖高领上衣 + 白色打底裤 + 白色平底鞋”，体型只写“苗条、成年、7 头身、长腿、细腰”。
- 仍被拦截：只传脸部特写和背面全身裁图；或者把服装改成宽松款；或者新开对话（被拦截过的对话更容易继续被拦截）。

## 2.5 修正（同一对话里追加，不要重新生成）
- 不等高或有透视：`Keep everything identical, but make all four views exactly the same height and strictly orthographic.`
- 头发碎：`Keep everything else unchanged; simplify the hair into fewer, larger, smooth clumps; remove all small curls and stray strands.`
- 腋下无空隙、裙子太长、衣服图露出身体、有高光：都按“Keep everything else unchanged; 只改一处”的句式追加。

## 2.6 交给 Tripo 之前
- 把 4 视图裁成 4 张**等高、居中、留白**的单图，文件名标 `front / left / back / right`。
- 做一张“裁剪检查总览”拼图，确认四张头顶、脚底对齐。
- 检查素体与服装两组图的比例、姿势一致（可以叠图）。

## 2.7 Tripo 输出的实际情况（实测）
- 多视图生成（multiview-to-model）导出 FBX：每个模型**归一化到最长边约 1 个单位**，以原点为中心。
- **朝向要实测**：大肥鱼第二版的 3 个 FBX 原样导入后，宽度沿 Y、高度沿 Z，正面朝 **+X**（不是 Blender 惯例的 −Y）。
  - 判断方法：先打印包围盒，再分别从 ±X、±Y 渲染一张，确认正面。`multiview_render.py --front` 可以指定朝向。
- 配件合集整张导入时，也是 Y-Z 平面上的一块拼板，要按连通片区拆分并命名（见 references/03）。
- Tripo 的**法线不可靠**：描边、射线内外判断都不要直接信任法线方向（见 references/03 的奇偶规则）。
- 生成评估：每个模型都要和输入四视图做剪影 IoU 对比，并出一张“Tripo×评估”拼图交给用户看。
  - 实例（大肥鱼 v1 素体）：前 0.90、右 0.74、后 0.83、左 0.73。
  - 白色围裙、荷叶边在浅底上会被当成背景，所以服装的 IoU 偏低，目视为准。
