# 08 导出、回读与交付

## 8.1 编辑源与交换资产分开
- 高分辨率编辑工程保留原贴图、复杂材质和可撤销遮罩。贴图简化、遮罩应用、材质转换都在临时副本里做。
- OC5 v016 的实例：GLB 约 12.6 MB、FBX 约 10.3 MB，含骨架、权重、动作和内嵌贴图；导出用 2K 底色和 1K 法线；原工程的 8K 贴图没有覆盖。

## 8.2 回读必须检查
- 对象数、骨骼数、角色高度、轴向、材质、贴图、动画帧范围、顶点是否随骨骼移动、有无非有限坐标。
- FBX 回读常有 **1 帧偏移**（例如 2–182），比较时要对齐。
- GLB 导入器会生成骨骼显示辅助物（`Icosphere`），统计尺寸和数量时要排除。
- 烘焙贴图要检查像素：尺寸、最小 / 最大值、均值、非黑像素比例，并亲眼看图。全黑的版本改名为 `REJECTED_*`，不要删除。
- 缩放或复制图像后，检查打包数据是否仍引用旧图。

## 8.3 交付清单
- 最终 `.blend`（指明是哪一个），以及物理缓存（MDD 或点缓存）。被引用的缓存文件也必须一起交付。
- 验收图、视频、数值报告 JSON、生成脚本（可复现）。
- README（模板见 templates/delivery_README_template.md）：状态、做法、数字、文件、残留问题、署名。
- 署名：用了 CMU 动捕就附上英文署名原文；用了 MIHOYO 模型要说明“只量取比例，没有复制几何”。
- 引擎验收（Humanoid 映射、实时物理、LOD）不在 Blender 交付范围内，除非用户明确要求。

## 8.4 展示（介绍视频 / 示例页）
- HTML+CSS 时间轴视频：每个场景用 `--start/--dur` 控制；示例卡片展示“立绘 → 拆件图 → Tripo 部件 → 拼装 → 绑定+卡通 → 动作+物理”。
- 动作卡片用精灵图：40 帧 × 300×525，CSS `steps(40)` 播放。抽帧范围要正好包含整数个周期（例如 16 帧周期，取 80 帧每 2 帧抽 1 帧），循环时才不会跳帧。
- 用 playwright 逐帧截图，再用 ffmpeg 编码导出 MP4；导出后要抽帧检查动作是否在动。
- 标签要如实：插件做的环节和 Blender 里另外完成的环节分开标注。
