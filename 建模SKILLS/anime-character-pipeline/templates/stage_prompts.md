# 各阶段任务描述模板（给 Agent / 每轮复述约束用）

> 用法：复制对应段落，把 <> 换成本角色的信息。每一轮都要把“不可变清单”和“用户意见”原样复述，不要省略。

## 装配（f）
以 <素体文件> 为唯一尺度基准，<唯一准确参考图> 为外观依据。先检查所有输入、坐标与连通片区，再做改动。
保留脸、表情、原 UV、原贴图和已验收的饰品位置（<列出位置值>）；不导入替代头模。逐件装配，源文件和备用件保留。
每次只修已确认的最大问题：<用户意见逐条>。
输出：同机位前后对比（正、左、背、右 + 特写 + 参考叠图）、结构报告 JSON；另存 <角色>_assembly_f<NNN>.blend，不覆盖。

## 绑定（r）
优先复用有效骨架；没有就按网格地标标定，并出关节标定图。自动权重只在“只含皮肤”的副本上计算，再传回。
只按变形骨归一化，每顶点 ≤ 4 个影响，未赋权皮肤为 0。头发和尾巴建骨链（<链数 × 节数>），裙子用布料代理 + Surface Deform。
姿势测试动作：f20 转头 / f40 抬臂 / f60 屈肘 / f80 屈膝 / f100 以后跑步。每个姿势出正面加侧面图。

## 物理（p）
先验证初始状态（无初始穿透、固定端、尺度）。裙子：低模代理 + 碰撞胶囊 + 预滚 + 取稳定周期 + 首尾交叉淡化。
头发和尾巴：带阻尼的角弹簧 + 重力预载 + 角度上限 + 碰撞放在最后；尾巴随裙子做整体平滑外摆，不接收逐帧推力。
验收：motion_metrics.py（加速度 p95、HF 占比、弦长比、弯曲 p95）+ 对象间相交面对数（静止 / 均值 / 最大）+ 三视图跟拍视频。
不通过的项目明确保留，不靠过滤失败区域得到零计数。

## 卡通渲染（t）
在独立分支里移植或调整 Toon 材质（插画式三层色阶 + 描边）。不改脸部几何，不用新贴图覆盖原贴图。
描边厚度按对象设定（身体约 0.0024、服装约 0.003、饰品约 0.0022）。可参考 Paper朱插件的描边修复和高光函数，但必须说明实际调用了哪些、在哪个 Blender 版本上。
改动前后跑 mesh_audit + compare_audit，证明拓扑、UV、坐标没变。正、背、侧、脸部特写都要看过。

## 交付
列出最终文件、当前候选、通过范围和未验证项。提供场景、缓存、贴图、预览、数值报告、文件哈希和使用说明。
没有完成完整验收的，标题和首段必须写明“预览版 / 未签署完整物理验收”。
